# Настройка предложки и модерации стены

Публичная форма доступна во вкладке «Стена». Предложения стримеров и публикации (текст и/или изображение) всегда получают статус `pending` и не видны посетителям до одобрения.

## Настройка постоянного хранения на Render

Рекомендуемый вариант — PostgreSQL: он не требует Persistent Disk и хранит заявки отдельно от файловой системы приложения.

1. Создайте PostgreSQL database в Render и скопируйте Internal Database URL, если база и Web Service находятся в одном регионе Render.
2. В Environment Web Service добавьте `DATABASE_URL` со значением строки подключения. Не публикуйте её и не добавляйте в GitHub.
3. При первом запуске с `DATABASE_URL` приложение создаст таблицу и импортирует существующий `data/community-submissions.json`, если этот файл доступен. После успешного импорта база станет основным хранилищем.
4. Также добавьте в Environment:
   - `WALL_ADMIN_PASSWORD` — уникальный длинный пароль владельца (не используйте пароль от GitHub).
   - `WALL_MODERATORS` — JSON-объект логинов выбранных модераторов и их индивидуальных паролей, например:
     ```json
     {"mod_one":"уникальный-длинный-пароль-1","mod_two":"уникальный-длинный-пароль-2"}
     ```
5. Сохраните переменные и дождитесь успешного деплоя. Вход владельца: логин `admin` и пароль из `WALL_ADMIN_PASSWORD`. Модераторы входят по логину-ключу и паролю из `WALL_MODERATORS`.
6. Для удаления доступа модератора удалите его запись из `WALL_MODERATORS` и выполните redeploy. Активные сессии живут до 12 часов или до выхода.

Если `DATABASE_URL` не задан, приложение продолжает использовать JSON-файл. На Render этот режим надёжен только с Persistent Disk; после перехода на PostgreSQL диск не требуется.

## Что умеет предложка

- Принимает никнейм автора без регистрации.
- Принимает ссылку Twitch для предложения стримера.
- Принимает текст и/или изображение JPG, PNG, WEBP, GIF до 2 МБ для стены.
- Ограничивает отправку с одного IP пятью заявками в час и проверяет тип/сигнатуру изображения.
- Даёт вошедшим модераторам одобрить, отклонить или удалить ожидающую заявку.
- Показывает на сайте только одобренные предложения и публикации.

Изображения и заявки хранятся в JSON-файле внутри `WALL_DATA_DIR`. Ограничьте доступ к Persistent Disk через настройки Render; не размещайте этот каталог внутри `public`.
