Оформи свой чат.

Выбирай стиль чата для трансляции, смотри пример сообщений и настраивай цвета. Выбери оформление, подключи публичный Twitch-чат и создай ссылку для Browser Source в OBS.

Подключить Twitch-чат для OBS

Создай персональную ссылку для Browser Source. Виджет получает сообщения публичного чата через Twitch IRC и отображает их в выбранном стиле.

В OBS: Источники → + → Браузер → вставь ссылку. Рекомендуемый размер: 420 × 760. Публичный чат не требует токена; для отправки сообщений из виджета авторизация не включена.
