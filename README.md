# 1°6 Community — статусы Twitch

## Что умеет
- Список 24 каналов в четырёх категориях: создатель, 1°6, другие классные стримеры и новые каналы для знакомства.
- Реальные статусы эфира через официальный Twitch Helix API.
- Если канал в эфире, показываются название трансляции и число зрителей.
- Проверка статусов в браузере каждые 60 секунд; сервер кэширует ответ Twitch на 30 секунд.
- Аватарки загружаются через DecAPI; при ошибке остаются локальные заглушки.

## Настройка
1. Установи Node.js 18 или новее.
2. Зарегистрируй приложение в Twitch Developer Console: https://dev.twitch.tv/console/apps
3. Скопируй Client ID и создай Client Secret.
4. Установи переменные окружения на сервере:
   - `TWITCH_CLIENT_ID`
   - `TWITCH_CLIENT_SECRET`
   Не вставляй секрет в HTML или в публичный репозиторий.
5. В терминале из папки проекта запусти:
   ```bash
   npm start
   ```
6. Открой `http://localhost:3000`.

## Размещение в интернете
Размести весь проект на Node.js-хостинге, который поддерживает переменные окружения (например, Render, Railway или VPS). Укажи `TWITCH_CLIENT_ID` и `TWITCH_CLIENT_SECRET` в настройках Environment/Secrets хостинга. Публиковать только папку `public` недостаточно: сервер нужен для безопасной авторизации в Twitch.

Если API временно недоступен или секреты не настроены, сайт покажет «СТАТУС НЕДОСТУПЕН», а не будет ошибочно утверждать, что стример офлайн.

## Последние изменения
- Добавлена кнопка «Случайный стример»: проверяет реальные статусы через `/api/streams` и переводит на случайный Twitch-канал из списка, который сейчас в эфире. Если ни один канал не в эфире, показывает «Сейчас никто не стримит». Если API недоступен, отображается отдельное сообщение об ошибке.
- Для PayPal, DonationAlerts и Telegram используются прозрачные SVG-иконки без белого фона; если источник значка недоступен, остаётся прозрачный текстовый значок.


- В меню анкеты, внутри строки Twitch (а не на компактной карточке), показывается количество фолловеров. Сервер получает публичный счётчик через DecAPI; ответ кешируется на сервере на 2 минуты. Если счётчик недоступен, отображается понятное сообщение, а не выдуманное число.
